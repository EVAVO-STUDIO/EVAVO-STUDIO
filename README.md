# EVAVO Studio

**Creative technology for ambitious digital products, interactive experiences and intelligent systems.**

EVAVO is an Australian boutique creative technology studio designing and engineering digital products, advanced web experiences, AI-enabled automation, interactive 3D, games and bespoke creative software.

We combine product thinking, visual design and software engineering to build complete systems — from interface and experience through automation, infrastructure, deployment and production tooling.

## What we build

**Digital products & platforms**  
Purpose-built web applications, client systems, operational software and product experiences.

**Creative engineering**  
Advanced frontend systems, interactive web, realtime graphics and bespoke creative tools.

**AI & automation**  
Governed automation, intelligent workflows, internal operations tooling and AI-enabled product experiences.

**3D, games & realtime**  
Godot and Three.js systems, 3D production pipelines, environments, materials, simulation and automated game QA.

**Construction technology**  
Project delivery, claims, compliance, commercial-control and client-facing digital systems for the built environment.

## Engineering

TypeScript · JavaScript · Python · C# · React · Next.js · Node.js · Godot · Three.js / WebGL · Cloudflare · Vercel

## Private by design

Most EVAVO client delivery, commercial product work, internal R&D and automation infrastructure is maintained in private repositories.

Public repositories are released selectively only after code, documentation, licensing, security and intellectual-property boundaries have been reviewed for external use.
