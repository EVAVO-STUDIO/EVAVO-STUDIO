# Security

EVAVO treats security reports as private information.

If you believe you have found a vulnerability affecting an EVAVO system, repository or digital product:

- do not publish the vulnerability, exploit details, credentials or sensitive data in a public GitHub issue;
- do not include live secrets, client data or personal information in a public report;
- contact EVAVO through https://evavo.com.au and identify the affected system or repository;
- provide only the minimum information needed to begin a private review.

EVAVO will coordinate a private reporting path where additional technical detail is required.

This repository is the public EVAVO Studio profile. Client delivery, internal infrastructure and proprietary production systems are private by default.
